# Catálogo Nike

Catálogo web de modelos Nike (hombre y mujer), independiente de cualquier tienda.

- `index.html` — catálogo interactivo: buscador, filtro por género, una tarjeta por cada color/referencia (199 en total) con ficha rápida.

Datos de producto (referencia, precio, color) tomados de listas de precios mayoristas Nike reales; imágenes y nombres de modelo verificados contra nike.com. 169 de las 199 tarjetas usan la foto exacta de ese color; las 30 restantes (colorway no encontrado en ningún storefront oficial de Nike) muestran una foto de referencia del mismo modelo y lo indican explícitamente. No incluye tallas por producto (la fuente original no las trae).
