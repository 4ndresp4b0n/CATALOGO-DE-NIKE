# Catálogo Nike

Catálogo web de modelos Nike (hombre y mujer), independiente de cualquier tienda.

- `index.html` — catálogo interactivo: buscador, filtro por género, ficha rápida de cada modelo.

Datos de producto (referencia, precio) tomados de listas de precios mayoristas Nike reales; imágenes y nombres de modelo verificados contra nike.com. No incluye tallas por producto (la fuente original no las trae).
